# Python Journey Projects 🚀🐍

## 📌 About the Project
This repository contains a collection of three distinct Python projects developed during the "Jornada Python" bootcamp. The projects progress from basic task automation to advanced data analysis and machine learning predictions.

## 📂 Repository Structure & Modules

The repository is divided into three main modules:

### 1️⃣ Class 1: Task Automation and Bots (`Aula 1 - Automações de Tarefas e Bots`)
Focused on automating repetitive tasks using Python.
* **`Atuomacao.py`**: Main script for the automation task.
* **`pegar_posicao.py`**: Utility script to capture mouse coordinates on the screen.
* **`gabarito.py`**: The completed reference code.
* **`produtos.csv`**: Dataset used for the automation process.
* **`Apostila Jornada Python - Aula 1.pdf`**: Course material and instructions.

### 2️⃣ Class 2: Data Analysis (`Aula 2 - Analisando Dados com Python`)
Focused on data manipulation and exploratory data analysis (EDA) to find insights about customer cancellations.
* **`inicial.ipynb`**: Starter Jupyter Notebook for the data analysis.
* **`gabarito.ipynb`**: The completed reference notebook.
* **`cancelamentos.csv`**: Dataset containing customer cancellation records.
* **`Apostila Jornada Python - Aula 2.pdf`**: Course material and instructions.

### 3️⃣ Class 3: Machine Learning Prediction (`Aula 3 - Projeto de Previsão com Machine Learning`)
Focused on building a Machine Learning model to predict customer behavior/churn.
* **`inicialC.ipynb`**: Starter Jupyter Notebook for building the predictive model.
* **`gabaritoC.ipynb`**: The completed reference notebook with the trained model.
* **`clientes.csv`**: Historical dataset used to train the model.
* **`novos_clientes.csv`**: Dataset with new customers to apply the predictive model.
* **`Apostila Jornada Python - Aula 3.pdf`**: Course material and instructions.

## 🛠️ Technologies Used
* **Language**: Python
* **Environment**: Jupyter Notebook / VS Code
* **Libraries (Expected)**: `pandas`, `pyautogui`, `scikit-learn` (or similar ML libraries)

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/Rafaration/python-journey-projects.git
   ```

2. Install the required dependencies (a virtual environment is recommended). Depending on the module you are running, you might need:
   ```bash
   pip install pandas pyautogui jupyter scikit-learn
   ```

3. **For Module 1**: Run the scripts directly in your terminal or IDE:
   ```bash
   python "Aula 1 - Automações de Tarefas e Bots/Atuomacao.py"
   ```

4. **For Modules 2 & 3**: Open the Jupyter Notebooks:
   ```bash
   jupyter notebook
   ```
   Navigate to the respective folders and open the `.ipynb` files.
